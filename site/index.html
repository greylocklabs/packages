Greylock Labs packages

The signed dnf and apt repository for Greylock Labs apps on Linux: Callie and Jot. Each app's installer adds it for you, so updates come with the system's. To add it by hand:

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/greylocklabs.repo https://packages.greylocklabs.org/rpm/greylocklabs.repo
sudo dnf install callie jot

Debian

sudo curl -fsSL -o /usr/share/keyrings/greylocklabs.asc https://packages.greylocklabs.org/greylocklabs.asc
sudo curl -fsSL -o /etc/apt/sources.list.d/greylocklabs.sources https://packages.greylocklabs.org/deb/greylocklabs.sources
sudo apt update && sudo apt install callie jot

Ubuntu

sudo curl -fsSL -o /usr/share/keyrings/greylocklabs.asc https://packages.greylocklabs.org/greylocklabs.asc
sudo curl -fsSL -o /etc/apt/sources.list.d/greylocklabs.sources https://packages.greylocklabs.org/deb/greylocklabs-ubuntu.sources
sudo apt update && sudo apt install callie

The key's fingerprint is 0936 1156 3109 8684 5012 EA9E 3E6A 2C1F AFEE ECEC. Packages are built by each app's release workflow on GitHub, and the repository is rebuilt from those releases by greylocklabs/packages.
